## What this is

**JsBarcode** R package: an `htmlwidget` that wraps the
[JsBarcode](https://github.com/lindell/JsBarcode) JavaScript library (vendored,
v3.12.3) to render 1D barcodes as SVG (RStudio viewer, R Markdown/Quarto, Shiny).

The repo root **is** the package. This file lives in `.claude/` and the plan in
`dev/` so that pkgdown does not publish them (pkgdown renders every root `*.md`).
The 2017 material (patched `htmlwidgets` clone, scaffolding script, `.Rhistory`,
bower sources of JsBarcode 3.8.0) lives outside the repo in
`../22-JsBarcode_legacy-2017/`. Do not bring it back.

## Conventions

- Everything in the repo is written in English: code, comments, docs,
  CLAUDE.md, PLAN.md, commit messages.
- R arguments are `snake_case`; `JsBarcode()` maps them to JsBarcode's
  camelCase option names (`bar_width` → `width`, `line_color` → `lineColor`, …).
  The widget's `width`/`height` are the container size, not the bars.
- Extra options go through `...` with their JS names and override the ones
  above (`utils::modifyList`). `NULL` options are dropped before reaching JS.
  Arguments after `...` must be named in full (avoids `font` matching
  `font_size`).
- Validate arguments in R with clear messages (`stop(..., call. = FALSE)`).
  Encoding errors (value not valid for the format) are shown inside the widget,
  not raised in R. In JS, invalid input is detected via JsBarcode's `valid`
  callback; any other exception is shown with its real message.
- Every behaviour change: a test in `tests/testthat/` plus a `NEWS.md` entry.
- Code must pass `make lint`. Fix lints rather than adding exclusions; only add
  a `.lintr` exclusion for a documented, deliberate exception.

## Updating the JsBarcode library

Automatic: `make update-js` (or `make update-js JSVER=x.y.z`). Manual steps:

1. `curl -sL https://registry.npmjs.org/jsbarcode/latest | jq -r .version`
2. Download `https://registry.npmjs.org/jsbarcode/-/jsbarcode-<ver>.tgz`, copy
   `package/dist/JsBarcode.all.min.js` and `package/MIT-LICENSE.txt` (as
   `LICENSE`) to `inst/htmlwidgets/lib/jsbarcode-<ver>/`, and delete the
   previous version's folder.
3. Update version/path in `JsBarcode.yaml`, the dependency test, README and
   NEWS. Review `src/barcodes/index.js` and the `valid()` methods of the new
   version and update `barcode_format_info` in `R/formats.R` (every `example`
   must render without error).
